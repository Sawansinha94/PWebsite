# 💕 A Secret Love Message Website

A beautiful, interactive website that reveals a romantic message after entering a secret code.

## Features

✨ **Interactive Lock Screen** - Enter a secret code to unlock the heart

💖 **Animated Reveal** - Beautiful animations when the correct code is entered

🎆 **Heart Burst Effects** - Celebratory heart animations on unlock

📱 **Responsive Design** - Works perfectly on all devices

🌈 **Gradient Background** - Stunning purple gradient with twinkling stars

❤️ **Exponential Love** - The message "I love you" multiplies infinitely

## How It Works

1. **Load the website** - You'll see a beautiful lock screen with a heart icon
2. **Enter the secret code** - Type the secret code and click "Enter" (or press Enter key)
3. **Unlock the message** - The screen transitions to reveal the romantic message
4. **See the reasons** - Browse through heartfelt reasons why you're loved
5. **Lock again** - Click "🔄 Lock Again" to reset and repeat

## Configuration

To change the secret code, open `script.js` and modify the `SECRET_CODE` variable:

```javascript
const SECRET_CODE = 'iloveher'; // Change this to your secret code
```

## Customization

### Change the Secret Code
Edit line 4 in `script.js`:
```javascript
const SECRET_CODE = 'your-secret-code-here';
```

### Change the Love Multiplier
Edit line 5 to control how many times "I love you" appears:
```javascript
const LOVE_MULTIPLIER = 100; // Increase or decrease this number
```

### Customize Reasons
Edit the reason cards in `index.html` (lines in the reasons-container) to add personal messages.

### Change Colors
Modify the gradient colors in `styles.css`:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```
